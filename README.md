# socialcrawl-superengine

Deep social research superengine on the SocialCrawl API: the full canon — 645 endpoints across 68 platform namespaces — with exact per-call credits, plus guided research plays — voice-of-customer mining, competitor ad-library recon, AI-visibility (GEO) audits, link-in-bio offer mapping, audience demographics, dev/tool radar — and priced big-gun one-shots (creator vetting, lead discovery, share-of-voice).

## Install

1. In Claude Code Desktop, open the plugin marketplace box (add marketplace).
2. Add `joeoliveimpact/socialcrawl-superengine`.
3. Install **socialcrawl-superengine**.

Or in the Claude Code CLI:

```
/plugin marketplace add joeoliveimpact/socialcrawl-superengine
/plugin install socialcrawl-superengine@socialcrawl-superengine
```

## Requirements

You need your own SocialCrawl API key.
